## User Stories — App companion DRAGONS

### Compte & accès

| En tant que | Je veux | Afin de |
| - | - | - |
| Visiteur | M'inscrire | Créer mon compte |
| Utilisateur | Me connecter | Accéder à mon compte |
| Utilisateur | Réinitialiser mon mot de passe | Récupérer l'accès à mon compte en cas d'oubli |
| Utilisateur | Me déconnecter | Sécuriser mon compte sur un appareil partagé |

### Personnages joueurs (PJ)

| En tant que | Je veux | Afin de |
| - | - | - |
| Utilisateur | Créer un personnage joueur | Être prêt pour une future session ou en rejoindre une en cours |
| Utilisateur | Consulter la feuille de mes PJ | Visualiser mes caractéristiques, inventaire et états |
| Utilisateur | Modifier la feuille de mon PJ lors d'événements précis (montée de niveau, choix à faire) | Faire évoluer mon personnage de façon encadrée |
| Utilisateur | Conserver l'expérience et l'inventaire d'un PJ entre les sessions | Rejouer un même personnage d'une aventure à l'autre |
| Utilisateur | Retirer un PJ d'une aventure sans le supprimer | Le mettre de côté tout en gardant sa progression |
| Utilisateur | Supprimer un de mes PJ | Nettoyer ma liste de personnages |

### Sessions de jeu

| En tant que | Je veux | Afin de |
| - | - | - |
| Utilisateur | Accéder à la liste de mes sessions de jeu | Retrouver et reprendre mes parties |
| Utilisateur | Parcourir une page recensant les sessions ouvertes | Trouver une session à rejoindre |
| Utilisateur | Rejoindre une session via un code d'invitation | Intégrer rapidement la table d'un meneur |
| Utilisateur | Envoyer une requête pour rejoindre une session listée | Demander l'accès à une partie qui m'intéresse |
| Utilisateur | Choisir avec quel PJ je participe à une session | Engager le bon personnage dans l'aventure |
| Utilisateur | Quitter une session | Me retirer d'une partie à laquelle je ne participe plus |
| Utilisateur | Recevoir une notification quand une action est lancée | Suivre en temps réel ce qui se passe à la table |

### Jeu (dés & combat)

| En tant que | Je veux | Afin de |
| - | - | - |
| Utilisateur | Lancer les dés | Résoudre une action de jeu |
| Utilisateur | Voir les jets de dés des autres PJ | Suivre les résolutions d'actions de la table |
| Utilisateur | Participer à un combat | Agir à mon tour pendant les affrontements |

### Meneur (rôle pris par session)

| En tant que | Je veux | Afin de |
| - | - | - |
| Utilisateur | Devenir meneur d'une nouvelle session | Mener une partie en tant que MJ |
| Meneur | Créer une session | Ouvrir une nouvelle partie |
| Meneur | Générer un code d'invitation pour ma session | Permettre à des joueurs de me rejoindre |
| Meneur | Accepter ou refuser les requêtes des joueurs | Contrôler qui rejoint ma table |
| Meneur | Lancer un événement aléatoire | Animer la partie avec de l'imprévu |
| Meneur | Lancer un combat | Démarrer un affrontement |
| Meneur | Lancer des dés cachés et en modifier le résultat | Garder la main sur la dramaturgie sans révéler mes jets |
| Meneur | Modifier la feuille d'un PJ lors d'un bonus ou malus infligé | Appliquer les conséquences du jeu sur les personnages |
| Meneur | Faire monter un PJ de niveau | Offrir une progression agréable et non frustrante |
| Meneur | Gérer des PNJ | Animer les personnages non-joueurs de l'aventure |

### Administration

| En tant que | Je veux | Afin de |
| - | - | - |
| Administrateur | Gérer les sessions | Modérer et maintenir les parties de la plateforme |
| Administrateur | Gérer les PJ | Modérer et maintenir les personnages de la plateforme |
| Administrateur | Gérer les utilisateurs | Modérer les comptes de la plateforme |
